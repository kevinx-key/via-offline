VIA 离线版 · K-STAR 定制（v1.0.3）
====================================

三平台绿色包，都是「下载即用、免安装」：

| 平台 | 文件 | 用法 |
|---|---|---|
| Windows 10/11 x64 | `VIA-Offline-KS-1.0.3-win-x64.exe` | 双击运行 |
| macOS（Apple Silicon） | `VIA-Offline-KS-1.0.3-mac-arm64.zip` | 解压得到 VIA-Offline-KS.app，拖进「应用程序」或任意目录双击 |
| macOS（Intel） | `VIA-Offline-KS-1.0.3-mac-x64.zip` | 同上 |
| Linux x86_64 | `VIA-Offline-KS-1.0.3-linux-x86_64.AppImage` | `chmod +x` 后直接运行 |

一、首次启动要注意
------------------
* **Windows**：exe 未签名，SmartScreen 会提示 →「更多信息 → 仍要运行」。
* **macOS**：未签名/未公证，双击会被 Gatekeeper 拦。右键 →「打开」，或执行：
    xattr -dr com.apple.quarantine /Applications/VIA-Offline-KS.app
  若提示“已损坏”，也是同一原因，用上面命令去掉隔离属性即可。
* **Linux**：AppImage 需要 FUSE；没有 FUSE 的发行版用
    ./VIA-Offline-KS-1.0.3-linux-x86_64.AppImage --appimage-extract-and-run

二、设置存放（绿色）
--------------------
* Windows：解压运行，设置在同目录 `VIA-Offline-Data`
* Linux：AppImage 旁的 `VIA-Offline-Data`
* macOS：遵循系统规范，在 `~/Library/Application Support/VIA-Offline-KS`
删掉对应目录即恢复默认设置，不写注册表、不装服务、不需要卸载程序。

三、这是什么
------------
基于 the-via/app（GPL-3.0）的**非官方**离线构建：插上键盘就能改键，全程不联网。
与 VIA 项目及其维护者无隶属或背书关系。

v1.0.3 的变化：
  * 新增 macOS（x64 / arm64）与 Linux AppImage 构建，全部由 GitHub Actions 产出
  * 品牌为 K-STAR；字体全部为开源许可（Fira Sans、Noto Sans Symbols / 2，均 OFL）
  * 移除「分享到 Gist」功能

四、离线保证
------------
键盘定义（3351 个 JSON）、字体、three.js 的 Draco 解码器全部打包；Chromium 的
拼写检查词典下载、组件更新、域名可靠性上报、sync、pings、DNS 预解析均已关闭，
解析器只放行 127.0.0.1/localhost，应用层再对非本机请求一律 cancel。

五、键盘识别
------------
随包 1898 个厂商产品 ID（= VIA 官方定义库构建快照），启动即预授权，插上键盘就被识别。
识别不到可运行仓库里的 `诊断-键盘.cmd`（Windows），或设置
`VIA_ALLOW_UNKNOWN_DEVICES=1` 放行未知设备。
