## 二、版权：GPL-3.0

the-via/app、the-via/keyboards 都是 GPL-3.0。我们分发的是**修改后的二进制**，因此触发以下义务：

| GPL-3.0 义务 | 我们怎么做的 | 结论 |
|---|---|---|
| 整体以 GPL-3.0 授权 | 仓库根目录 `LICENSE` | ✅ |
| 提供对应源码 | 公开仓库 + Release 说明里的源码链接 | ✅（§6(d) 同一地点提供） |
| 保留版权与许可声明 | 保留上游文件头；LICENSE/NOTICE 随包 | ✅ |
| 标注「已修改」及日期（§5a） | NOTICE.md 汇总 + 本次给修改文件加文件头注释 | ✅（已补） |
| 不额外施加限制 | 未加限制条款 | ✅ |

**注意**：GPL 只给版权许可，**不给商标许可**。所以「源码开源」不等于「可以叫 VIA」。

另一处细节：上游 README 里提到社区离线版（cebby2420/via-desktop）并声明无官方关联 —— 这说明
「另做一个离线版」本身是被上游知晓且不反对的形态，不构成额外风险。

## 三、商标

### 3.1 旧品牌名（v1.0.1 之前）— 高风险，已整改

v1.0.1 之前使用的品牌名与一家美国公司持有的电子产品商标（第 9 类计算机软件/电子设备、
第 42 类等，属驰名商标）过于接近，存在两类主张空间：

- **混淆可能**：同类商品（键盘、软件）上的近似名称，消费者可能误认为存在关联；
- **驰名商标淡化**：即使类别不同，驰名商标可跨类保护。

风险高低取决于：是否商业化、是否面向美国市场、是否在键盘/电子品类做硬件销售。

**整改（已完成，v1.0.1 起）**
1. 品牌更名为 **K-STAR**，仓库名、安装包、界面、发布页、文档全部同步；
2. 旧名不再出现在任何交付物中（源码、二进制元数据、发布页、仓库描述）；
3. 后续建议：对 K-STAR 做一次商标检索（中国 CNIPA、美国 USPTO、欧盟 EUIPO，第 9 / 15 / 42 类），
   长期做就尽早申请注册（中国第 9 类 + 第 42 类）。

### 3.2 「VIA」的使用 — 低-中

- 用来描述「兼容 / 基于 VIA 源码」属于**描述性使用（nominative use）**，通常可接受；
- 但产品名若叫「VIA 离线版」，可能被理解为官方版本。缓解措施已经做了：顶栏常驻
  「非官方」标识、移除 VIA 字形 logo、页面与 NOTICE 明确声明无隶属关系；
- 不要再使用 VIA 的 logo/图标做图标或宣传图（已替换为星标）。

### 3.3 页面文案

`/via` 与 `/via/docs` 里对 VIA 的提及均为事实性描述（「基于 the-via/app」），并带非官方声明，
符合描述性使用的常见做法。

## 四、第三方资产

| 资产 | 许可 | 处置 |

| Fira Sans / Fira Sans Condensed | SIL OFL 1.1 | 已补 `public/fonts/fira/OFL.txt` |

| Symbola.ttf | 授权不明（George Douros） | ✅ v1.0.2 已移除，改用 Noto Sans Symbols / 2（OFL） |

| Electron / Chromium | MIT / BSD 类 | ✅ 发行包内含许可文件 |

**Gotham Rounded 是这里最大的隐藏风险**：上游 the-via/app 把 Gotham Rounded 的 webfont 放进了
仓库并在 CSS 里引用（`GothamRounded` 字族）。若上游并未取得「随 GPL 源码再分发」的授权，
我们再分发同样可能侵权，且这种风险会随下载量放大。

处置建议（按成本排序）：
1. 确认上游是否有可再分发的 webfont 授权（看 their repo 的 LICENSE/NOTICE，或直接问上游）；
2. 若无法确认，**替换成开源近似字体**（Montserrat / Nunito / Poppins 都是几何无衬线，
   字形接近 Gotham Rounded），并把 CSS 里的 `GothamRounded*` 字族改掉；
3. 若只做内部使用不分发，风险显著降低（但你们是要公开下载的）。

本次没有替换字体（会改变 UI 观感，需要你拍板）。

## 五、网站页面

- **代码与文案**：本次 `/via`、`/via/docs` 是自写组件，没有复制 usevia.app 的 HTML/CSS/图片/文案 → 版权风险低；
- **版式**：只借鉴了「居中 logo + 标语 + 下载按钮」这种通用落地页结构，不构成「有一定影响的装潢」的近似；
- 页面里已写明「非官方构建」「GPL-3.0」「源码在仓库」，并把下载指向 GitHub Releases → 与 GPL 的
  源码提供义务一致；
- 若要更稳：在 `/via` 页脚加一行「VIA 为其权利人商标，本页仅作兼容性说明」。
